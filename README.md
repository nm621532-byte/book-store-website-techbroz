# 📚 Kitaab Ghar — Book Store Website (HTML CSS JS)

Ek complete chhoti **book store website** — sirf HTML, CSS aur JavaScript se, **neubrutalism** design mein (yellow background, mote black borders, hard shadow, bento grid). Tech Bro Z ke 8 AM Short mein ise live banaya aur redesign kiya 🔥

🌐 **Live demo:** https://nm621532-byte.github.io/book-store-website-techbroz/

## Isme kya hai
- Books ki list (Rich Dad, Wings of Fire, Atomic Habits, Godaan) — JavaScript `map()` se har book ka tile
- **Buy** button dabao → Cart count badhta hai
- Bento grid: bada pink hero tile + book tiles
- Neubrutalism: `border: 4px solid #000` + `box-shadow: 6px 6px 0 #000`
- Fonts: Archivo Black + Space Grotesk (Google Fonts)

## Khud chalao
1. Repo download karo (Code → Download ZIP) ya `git clone https://github.com/nm621532-byte/book-store-website-techbroz.git`
2. `index.html` browser mein kholo — bas! Koi install nahi.
3. Nayi book add karni hai? `script.js` mein `books` list mein ek line jodo: `["Gitanjali", 199, "📓"],`

💻 Free online editor: https://techbroz-code.sites.tab.bot/ (wahan "🌐 Website live karo" dabao aur apni site online karo)
